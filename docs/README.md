# docs

## Purpose

Documentation for users and contributors that does not fit in the top-level
[README](../README.md): guides, references and conventions.

## What goes here

- Contributor conventions — start with
  [`repository-layout.md`](repository-layout.md).
- Template authoring guide, deployment guide, API reference and operational
  runbooks, as they are written.

## What does not go here

- Code comments or API docs generated from code — they live with the code.
- Design history and analysis — kept in the companion repository
  [dotnet-report-service-sdlc](https://github.com/EugenioSerrano/dotnet-report-service-sdlc).

## Naming

kebab-case Markdown files (`template-authoring.md`, `deployment.md`); a
sub-folder only when a topic needs several pages.

# samples

## Purpose

Material for **adopters**: examples that show how to use dotnet-report-service
and that anyone can run against a local instance.

## What goes here

- `templates/<template-id>/` — sample template packages (manifest, schema,
  sample data, template parts, styles, assets), one per template.
- `datasets/` — the seeded synthetic pilot datasets (simple; grouped with
  subtotals; high volume) and the generator that produces them
  reproducibly.

## What does not go here

- Product code → [`../src/`](../src/).
- Internal experiments and measurements → [`../spikes/`](../spikes/).
- Real customer data or anything containing personal data — never.

## Naming

Template folders use the template id in kebab-case (for example
`samples/templates/invoice-energy/`). Dataset files are named after their
profile and size (for example `header-items-v1.grouped.10k.json`) and are
regenerated by the generator rather than edited by hand.
